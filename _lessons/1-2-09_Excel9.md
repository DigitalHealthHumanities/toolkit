As compared to SUBSTITUTE or CONCATENATE the LEFT function is very simple. It basically functions by looking to a take a {% include term.html term="string" %} of characters, count to a specific number of those characters starting from the left most one, and delete any characters beyond the number counted to.

Let’s use the example from our substitute lesson:

    =LEFT(“Aisha left for the store at 8:28am”,8)

Would output

    Aisha le

It is important to remember that the left function will include spaces. Also if it is given a string of text that is shorter than its count, it will leave it the same. 

    =LEFT(“Aisha”,8)

Would output

    Aisha

There is a corresponding command, RIGHT, that does the same for the right-most characters. Both of these commands can be useful if you are trying to programmatically change text in specific ways to make it easier for other software to access and analyze. (If you have categories that are the exact same number of characters, you can uniformly transform them across the whole data set.)

What we want to do is use the Left function to keep our file names manageable. Let’s cut off the name of the document at 10 characters. In the J3 cell, write

    =LEFT(I3,10)

The output should read

    WarSurgery

We want to do the substitute function first, because if we remove characters after we do the left, we will not get uniformly long text. If we transformed the book title “War and Peace” with left first, we would get “War and Pe” and then if you run the substitute function, the final text would read “WarandPe”. If you did it in the order we did in the lesson above, the result would be “WarandPeac”. While this is not a research endingly bad issue, the order of operations can and will change how Excel outputs its information. 

Now let us combine all of these different outputs together:

    =CONCATENATE(J2,”_”,E2,”_”F2)

This gives us

    WarSurgery_Wallace_1918

What is important to remember is that Excel can be used to transform textual information in ways that can clean or manage more complex or messy data. We are only scratching the surface on the ways functions can be used to automate these processes, but those practices would involve their own semester-long course!
