<div class="backsplash">For this exercise, you will need to download the Excel Learning Workbook.<br><br> For this and the following exercises, we will be using the ReferenceWorksheet2 sheet.</div>  

The function in Excel that we will cover in this lesson is the Data Validation Tool. This tool can be used to help structure cells to allow only specific kinds of inputs—like only inputting numbers, or only inputting a specifically predefined textual options. We are going to use a reference sheet—the DataForRW2 sheet in our workbook—to create categories to assist with data entry.

Click to the ReferenceWorksheet2 sheet, and select the C2 cell. This cell shows what we are trying to generate: a cell that has a drop down carrot that allows for the selection of a few predefined entries.

We’ll select one cell, C3, and press the Data Validation Button in Data > Data Tools > Data Validation.


{% include imgwithcaption.html filepath="/assets/img/Excel28_Captions.jpg" alt="A screenshot the Excel Data Tab. A box highlights the tab header with the caption ‘You Need to be in the Data Tab’. A second box highlights the button to activate the Data Validation tool. When you push the button for the Data Validation Tool, you will get an interface similar to the Text to Columns Wizard. We have to adjust some of the settings. First, change the “Allow” criteria to “List”. This will tell Excel to validate using a list from a source within the Excel spreadsheet.

The source we want is found in the DataForRW2 sheet, cells A2 to A5. You can write out the source in the Source box,

    =DataForRW2!$A$2:$A$5

Or, once you click into the Source Box, you can highlight and select those cells manually.



{% include imgwithcaption.html filepath="/assets/img/Excel14.jpg" alt="A screenshot the Data Validation Tool. The 'Settings' Tab is selected. The 'Allow' entry area has ‘List’. The ‘Data’ entry area is greyed out. Both ‘Ignore blank’ and ‘In-cell dropdown are checked’ and the Source area the code ‘=DataForRW2!$A$2:$A$5’ written in the text entry box." caption="You will want to double check that the ‘In-cell Dropdown’ option is checked, because it is important for the dropdown functionality we are going for in this lesson." %}


We are using the “$” character because we’ll be copying this down the row, and we don’t want our selection to change as we copy the information. (Excel will enter these automatically when you select the text manually.) Press “OK” and you will find that the cell now has an arrow next to it when you select it. It is referencing the cells in the other sheet, which have the corresponding information to the data. 

Press “OK” and you should see the cell you selected change and have a carrot next to it. Click on that and you should see the options from the DataForRW2 worksheet. If you select one of the options, it will automatically fill the cell.

This can be a helpful feature if you have preformatted information that you want to fill in the workbook.
