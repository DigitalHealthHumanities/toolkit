Another way to combine annotations and images for research or teaching purposes is with tools developed to guide viewers through a curated experience. We can do this through Storiiies (with three i’s for IIIF), developed by CogApp.

We can see one example of a narrative presentation at [this link](https://storiiies.cogapp.com/viewer/aeqi/The-Stoning-of-Saint-Stephen).

Storiies can use IIIF to add annotations to images. For now, let’s upload a JPEG file and annotate that image next. You could also start using Storiiies Editor by pasting in a manifest, however, there is currently a technical issue that CogApp has been trying to fix.

Storiiies is free to use. All services including image uploads and access to created stories are provided ‘as is’. They make no warranty as to future availability of images and stories and also reserve the right to restrict access and change the conditions of service at any time.

[Here is an example from a collection by Danielle Reay and her colleagues at Drew University who showcased manuscripts through Storiiies for pedagogical purposes](https://storiiies.cogapp.com/viewer/391d3/Drew-University-Shahnama-Paper-Conservation).

IIIF Image API through the Internet Archive
You can upload your pictures and have one IIIF Image API service through the Internet Archive.
* You can delete your images after 30 days if you just want to practice now.
1.	Register for a user account at https://archive.org
2.	Upload your image
3.	Upload one image per item
4.	Select Community Image collection
5.	On the details page, get the identifier for the image. That might look like this: img-1111_222222
6.	Some of the IIIF images might appear very small even if you uploaded a large image. In that case, add the filename to the URL to get the original image available as IIIF compliant.<br>Some images are appearing small, so you will need to add the filename to the URL. https://archive.org/details/img- ... followed by your image specific information You would normally create the following URL:<br>https://iiif.archivelab.org/iiif/img-[your image specific information]/info.json but to make the image larger, you need to add the filename ($IMG_	jpg):<br>https://iiif.archivelab.org/iiif/img-...$IMG_	jpg/info.json<br>To find the image, navigate to the details page: https://archive.org/details/img-...<br>Click on the main image. This will show the image full screen and if you look in the address bar, you will be able to see the filename.
7.	Now, use the Internet Archive image service with this identifier: https://iiif.archivelab.org/iiif/img-.../info.json
8.	You should then be able to use this image and create an image link: https://iiif.archivelab.org/iiif/img-.../full/512,/0/default.jpg
9.	Check that it works with a zooming viewer. For an image uploaded via the Internet Archive, we use the OpenSeaDragon Viewer:
https://iiif.gdmrdigital.com/openseadragon/index.html? plus your image-specific string, followed by /info.json, or http://openseadragon.github.io and a browser extension.
