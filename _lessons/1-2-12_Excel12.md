Let’s do one more count of all the different image genres in the dataset, on the ReferenceWorkseet1 sheet. These are found in column J.

What you will notice is that there are multiple {% include term.html term="string" %} that have been attached together using a comma as a separator. If we were to create a list of unique entries from this data, we will need to do something to the data in the column, because the COUNTIF function only looks at the whole string, and not elements within the string.

We can break that apart by using the “Text to Columns” function in the Data tab at the top of the screen. Navigate to Data, Data Tools, Text to Columns while selecting the J column in ReferenceWorksheet1.

When you open the Text to Columns pane, you’ll get this interface. You’ll want to select “delimited”—which refers to a specific character or set of characters that will separate into columns. The “Fixed width” option works if you have very structured forms of data (like four letter acronyms for every entry), but this is less common for text-based datasets.

# Why this Matters

There might be times in your research you’ll need to break apart materials, or create new ones. The text to columns feature is an important one to know about in the generation of certain lower code data workflows.

At other times you may need to count or find unique variables in a larger dataset to understand some broad trends across the dataset. You could use these outcomes to make more complicated formulas that cross reference materials in different cells.
