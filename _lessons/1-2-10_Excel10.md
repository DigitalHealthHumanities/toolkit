For this exercise we will learn how to use functions to analyze and process data from within our spreadsheet.

What do you see when you look at the ReferenceWorksheet1?

This spreadsheet is a collection of over 400 entries related to images in a small collection of books. This is part of a larger dataset developed by Sean Purcell as part of his [dissertation research](https://tuberculosisspecimen.github.io/diss/dissertation/X_1_1). You should notice a few things about this material: first it is similar to the citation information from the previous sheet, but it does not have any of its original formulas. (They were lost when copied from another spreadsheet program, Airtable.)

What we will do in this exercise is process a few specific data points from this larger collection, by cross referencing different cells.

We’ll first need a blank sheet to work on. So on the bottom of the Excel interface, click on the + symbol next to the sheets.

We will not need to rename this new sheet for this exercise, but if you’d like to, you can right click the Sheet1 that you just made and click “Rename”.

What we are going to do in this exercise is generate a list of the different image types in the dataset and then count how many times those image types show up in the entire sheet.

To do this, we will need to learn a few more functions and learn how to cross-reference sheets. In same way we can use a [Letter][Number] demarcation to describe a unique cell in a spreadsheet, we reference other sheets using similarly structured command. To do this, we add a prefix to our cell identifier, with the name of the sheet and an exclamation point (!).

    [SheetName]![Letter][Number]

It is important to know that if your sheet has spaces in it, you will need to {% include term.html term="escape" %} the sheet name.

    “[Sheet name with spaces]”![Letter][Number]

For this exercise, we are going to learn the UNIQUE function. UNIQUE looks at an array of cells lists every unique string that appears in that cell array. We want to get all of the unique variables in the C column in ReferenceWorksheet1.

Type out in cell A1 of your newly made sheet this command:

    =unique(ReferenceWorksheet1!C:C)

We are doing a few new concepts joined together, so let’s break down the command some.

First, we are referencing our other sheet using the “[SheetName]!” prefix. We are also referencing a whole column by not adding numbers to our cell identifiers. “C:C” basically means that you want the function to check every cell in the C column. If we wanted to reference multiple columns, we can create an array like “C:D" or “C:G”.

<div class=”backsplash”><strong>A Helpful Organizational Note:</strong> This formulation also means that we have to be careful about how we arrange our columns when we are building a dataset. If, at one point, I need to access all of the information in only two columns for a specific function and they are not next to each other (columns C and F for example), I will have to reform that data (either in a separate sheet or by rearranging the sheet in which I am working) to make the function work.<br><br>We will see this in action when we learn the VLOOKUP function later in this module.</div>

You’ll notice that unique generates an output in multiple cells. When using this function it is important to make sure you have enough open cells into which the formula will generate.  is the output:

|Image Type|
|X-Ray|
|Illustration|
|Photograph|
|Graphic|
|0|

The output has a couple outliers, which you may not have been expecting. First is the “Image Type” which is the heading for the column in the spreadsheet, and finally there is a 0 which is referencing every cell in the column that has no entry. We can fix this by being a bit more specific in how we reference our cells. Rewrite the formula:

    =unique(ReferenceWorksheet1!C2:C418)

And you’ll get this output:

|X-Ray|
|Illustration|
|Photograph|
|Graphic|

<div class=”backsplash”>Before we move to the next section, there is one finicky problem with the UNIQUE function we want to flag: UNIQUE is very good at looking at a single column of data, but when it references multiple columns, it will look for unique rows and not cells.</div>
