Let’s return to our workbook. We have an example file name already written in B2. Let’s try to copy that format in B3, using the Cuthburt Wallace citation.

Here is our example output:

Bookbyasma_Smartypants_1905

It looks like it is drawing information from the Title, Author Last, and Date columns, using underscores to separate the categories.[^2]

The output is like this:

    [Title]_[Author Last]_[Date]

And it is accomplished through this function:

    =CONCATENATE(C3,”_”,E3,”_”,F3)

What happens when you enter that formula into the B3 cell? We get 

    War Surgery of the Abdomen_Wallace_1918

This is a problem for two reasons: 1) Spaces can cause some digital tools to glitch or break, and 2) if we have a book with a very long title, we may have a file name with a similarly long title. Let’s clean that up with two more text editing functions—SUBSTITUTE and LEFT.

First, we are going to use the SUBSTITUTE function to delete any pesky spaces, and then, in the next lesson, we will use the LEFT function to reduce the length of our output string. 

The substitute function takes a defined combination of characters, searches within a text-based cell and replaces any matching characters in the {% include term.html term="string" %} with a new combination of characters. This function is written like this:

        =SUBSTITUTE([cell],”[stringtobesubstituted]”,”[stringreplacingthesubstitutedcharacters]”)

Let’s look at this command in plain grammar. Say you have a sentence, “Aisha left for the store at 8:28am”, but you want to change the name Aisha to Allison. You could write a function that says, reads “look for all instances of ‘Aisha’ and replace them with “Allison”. You would write:

   =SUBSTITUTE (“Aisha left for the store at 8:28am”,”Aisha”,”Allison”)

The result of this formula would be

    Allison left for the store at 8:28am.

If we wanted to change the original time, where Aisha leaves at 9:28am instead of 8:28am, we could do a similar function.

=SUBSTITUTE(“Aisha left for the store at 8:28am”,“8”,”9”)

You may notice that the output of this function is wrong: it reads “Aisha left for the store at 9:29am” and not “9:28am”. Rememember, when using the substitute function, it will replace **every instance of the selected string with the new string**. A function like

    =SUBSTITUTE(“Aisha left for the store at 8:28am”,”e”,”x”)

Would output

    Aisha lxft for the storx at 8:28am.

We can solve this, in our simple test case in two ways.

We can either be more specific in our find and replace

    =SUBSTITUTE(“Aisha left for the store at 8:28am”,”8:28”,”9:28”)

Or have Excel replace only the first instance, by adding a 1 to our function at the end.

   =SUBSTITUTE(“Aisha left for the store at 8:28am”,”8”,”9”,1)

We are going into detail about this function because it is very powerful. We can use substitute to clean text, and we can use it to add or remove information at larger scales within our Excel Files. It is also a little unintuitive, in the same way a lot of other Excel functions can be hard to initially grasp. It is a great test case to learn some of the weird ways Excel is programmed to process information.

With that in mind, let’s use the substitute function to erase spaces in our text. In the I3 cell, type in:

   =SUBSTITUTE(C3,” “,””)

In plain English, this command would read. Take text from the C3 cell, look for spaces, and then replace them with nothing.

We get a final result

    WarSurgeryoftheAbdomen
