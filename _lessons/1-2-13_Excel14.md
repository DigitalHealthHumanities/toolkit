<div class="backsplash">For this exercise, you will need to download the Excel Learning Workbook.<br><br> For this and the following exercises, we will be using the ReferenceWorksheet2 sheet.</div>  

Another way you can use a separate sheet to help with data entry is using the VLOOKUP function. This function allows you to automatically fill information that has been entered elsewhere in your Excel project.

VLOOKUP is both very powerful and also unintuitive, because it requires the information to be setup in a structured way. Most simply, the function looks to a reference array and outputs a text {% include term.html term="string" %} from a cell in the row that has data that matches an input string. We can use data in a reference sheet to autofill corresponding data.

The problem with VLOOKUP is that it requires our data to be very specifically structured: it looks to match the input string in the left-most column in an array, that cell has to have a unique value to all of the other cells in the column, and all of the data we want to copy has to be found in a single column. This means that we can only draw on specific kinds of data in our sheet, and we have to be very careful how we organize that sheet at the start. 

Go to the G2 cell in the ReferenceWorksheet2. We will use the VLOOKUP function to automatically fill in information related to the author’s first name.

The VLOOKUP formula works as follows:

<div class=”backsplash”>=VLOOKUP([reference value],[table array that contains the value],[the column number which contains the cell you want to output],[True or False statement for exact matches])</div>

In more plain English, the formula asks for a reference value (usually a cell), looks for whether that value appears in a separate array, and then outputs the value of the cell in the selected column and the same row of the cell that matches the reference value. It is complicated, so we should just tinker with it some.

Go to the G2 cell in the ReferenceWorksheet2 sheet. This whole column is blank, so we will auto populate the column, with the VLOOKUP function using data from columns C, D and E in the DataforRW2 sheet.

For this example, we are going to use an author’s last to autofill the author’s first name in the sheet. Here is the VLOOKUP command for G2:

    =VLOOKUP(F2,DataForRW2!D2:E5,2,FALSE)

In plain English the command reads: find the value in F2 in the first column in the data array (D2:E5), and if there is a row with the exact F2 value output the value of found in the same row as the matching value and the second column of the array.

If we do the drag and copy function, this formula will break, so we will need to freeze some of the elements.

Here is the best formula to drag and copy the formula.

    =VLOOKUP(F2,DataForRW2!D$2:E$5,2,FALSE)

One of the great things about VLOOKUP is that once the formula is in place, you can change values in the reference cell and it will catch up. So if you type “Hrdlicka” in F2, the G2 output will automatically change to “Ales”.
