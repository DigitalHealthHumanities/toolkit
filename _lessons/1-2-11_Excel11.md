Now that we have learned the UNIQUE function, let’s try using that information to analyze the material in the ReferenceWorksheet1 sheet, using the COUNTIF function.

COUNTIF looks at a range of cells and counts whether those cells contain {% include term.html term="string" %} of text that match a reference cell or string. It is written like this:

    =countif([cellrange],[criteria])

Write, in the blank spreadsheet you used for the previous lesson on the UNIQUE function, this formula in cell B1:

    =countif(ReferenceWorksheet1!C2:C418,A1)

This formula instructs Excel to do is as follows: Count the amount of times the string in cell A1 occurs in the cells C2 through C418 on ReferenceWorksheet1.

We can drag this formula down from B1 to B4.

There is one problem. As you drag the formula down, it will change all numbers in that formula by 1 for every cell it moves down. So B2 reads,

=COUNTIF(ReferenceWorksheet1!C3:C419,A2)

This is a problem because now we are having Excel look to the wrong cell range (we want it to read “C2:C418”). When we drag a cell down to copy the formula into the cell below it, Excel is doing a quick bit of math to replicate the formula to match that drag: it takes any cell reference and adds 1. So our “C2:C418” reference in B1 becomes “C3:C419” in B2.  If you drag the formula down from B1 to B10, the cell would read

     =COUNTIF(ReferenceWorksheet1!C11:C427,A10)

and the more I drag it down, the more out of sync with my data it will be come. 

<div style=”backsplash”>This will also happen if we drag a formula left or right, but instead of adding a number, it will adjust it one letter designation, from A to B to C and so on.</div>

What we need to do is freeze part of the coordinates equation, while keeping other coordinates in the equation transformable. To do this, we are going to use the “$” symbol in our function ahead of the coordinate we want to freeze. This equation, which we want to adjust to follow the data in the A column, we would be written as:

    =COUNTIF(ReferenceWorksheet1!C$2:C$418,A1)

The “$” symbol is being written on the number coordinates in the array we are referencing in the other sheet. In our function above it is written as follows:

    [ColumnLetter]$[RowNumber]

The $ will freeze the number or letter that directly follows it, so when you copy it into other cells, it will keep that number the same.

Let’s try incorporating the UNIQUE and COUNTIF functions together. Try using the UNIQUE Function to create a list of unique “Publication Types” in the ReferenceWorksheet1 sheet, and then try creating a COUNTIF function to count those results.
