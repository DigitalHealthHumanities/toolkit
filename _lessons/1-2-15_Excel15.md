Let’s try using VLOOKUP to automatically add book title information in the E column of the ReferenceWorksheet2 sheet.

As you may already be aware, and may have noticed in the previous lesson, our data column is going to cause some issues for us when we use the VLOOKUP function, because the data we want to output is in the left most column, so if we type a function like this--

    =VLOOKUP(F2,DataforRW2!,C$2:E$5,1,FALSE)

--The function will break.

This means we have to adjust our data table. Try to fix it yourself. We will have our answers below.

#H3 One more Detail About VLOOKUP and Other Reference Materials

Sometimes we have to force our data into a certain place for it to function in Excel, and sometimes we only realize we need it in a certain shape or form after we have done all of the work inputting the data. This is a common problem that can be solved with a few different solutions.

If you need a place to put in auto-filling or reference information, you can always create a second data sheet—like the DataForRW2 sheet in our example worksheet. You can also create replicated columns or rows in your main spreadsheet, and hide them by right clicking the columns and selecting the “Hide” option. You can unhide, by selecting the columns/rows before and after the hidden columns/rows and right clicking and selecting the “Unhide” option.

Hiding data allows you to shape the spreadsheet in a specific way, while keeping the data organized in the way that is best for direct interaction.
