Excel has all of these helpful tools and equations that help process data. Oftentimes, though, you will not be using Excel for your final analysis. You may be transporting that data to another program or tool to produce observations, findings, or visualizations. We do this a few different times in this toolkit, including in our introduction to Gephi. 

Excel is a great program for formatting and preparing data for use in different programs, but in order for it to be useful, we need to understand how to get information out of Excel’s proprietary file types.

Click on the File button at the top of the Excel interface and from there click on the “Save As” button. Some of the more recent changes to the Microsoft Office platform and Microsoft 365 has been a change in how the program offers exports. “Save As” is an old function that allows you to create a copy of the current project in a new file, usually named differently than the original. Click on the dropdown tab that is below the Downloads heading and above the “Save” button. You’ll see a bunch of different file types that Excel can save into. (If you want a more standard looking version of this interface you can also press the “more options” link.)

For exporting to other programs, ranging from ArcGIS to code-based analysis programs like R, we will want to use either .csv –short for comma separated values—or .tsv—short for tab separated values—as our export of choice.

*Helpful Information: What is a Comma Separated Value File?*
Comma Separated Value files organize your tabular data using commas as a delimiter. If I have a table in excel that reads

|Name (Last)|Name (First)|Affiliation
|Doe|John|University of California San Francisco|
|Johnson|Julia|University of California Berkeley|

A comma separated value file would represent this in an entirely textual way. The file would read:

<div class=”backsplash”>“Name (Last)”,”Name (First)”,”Affiliation”<br>“Doe”,”John”,”University of California San Francisco”<br>“Johnson”,”Jane”,”University of California Berkeley”</div>

What you should notice is that the columns are split using the “,” in each line, and each line is split using the line break. What is helpful about these files is that 1) they are entirely text-based, so they don’t have messy formatting or other data that could cause issues and 2) CSV files follow open source, non-proprietary guidelines. They are easier to work with across platforms, and they are more reliable when it comes to long-term sustainability.

Let’s try exporting our file as a .csv file. Going back to File>Save As change the file to CSV.

Now, you will have run into an issue. CSV files do not support multiple sheets. This means that in order to save each of these sheets, we’d need to save them one at a time.

Click “cancel” and navigate to the ReferenceWorksheet1 sheet, and then do the same “Save As”: File>Save As and select .csv. When you get the error message press “Ok”. When you do you should find a ExcelLearningWorkbook.csv in whatever folder you were working in. You can open this back up in Excel, but let’s open it instead with a text editor.
